# Sportmetryx — Combined Data

Generated by `build_combined_csv.py` from the 14 source CSVs (copies in `source/`).

## Outputs

### 1. `Sportmetryx_Combined_All_Data.csv` — everything in one file
Every row of every source file stacked into one CSV: **33,646 rows × 99 columns**.

- `source_file` / `record_type` — which file the row came from
  (`users`, `roster`, `baselines`, `training-sessions`, `performance-scores`,
  `score-components`, `score-drivers`, `validity-checks`, `observations`,
  `consent-records`, `interventions`, `intervention-reviews`, `athletes`, `sessions`)
- `date_iso` — unified event date (`YYYY-MM-DD`) parsed from each file's date column
- All source columns merged; columns whose name is used by multiple files with
  different meanings are qualified, e.g. `Session Type` vs `Baseline Type` vs
  `Observation Type` vs `Driver Type`, `Roster Status` vs `Baseline Status` vs
  `Consent Status` vs `Intervention Status`, `Score Timestamp` vs `Observation Timestamp`.

> Note: the `athletes` + `sessions` research dataset uses `ATH-xxx` IDs and its own
> schema; it is included in this file with its columns merged in (unmatched columns
> are blank per row).

### 2. `Sportmetryx_Combined_Wide_Athlete_Day.csv` — analysis-ready
One row per **athlete per day**: **1,362 rows × 106 columns** (demo dataset).

- Athlete-level: Team, Position, Roster Role/Status, Born, Consent, Baseline
  Start/End/Status/Version, Consent Status, Intervention fields, Review fields
- Score-level: Score, Band, Confidence, Validity, Reason
- 7 score components pivoted to `… Norm / Original / Unit / Contribution`
- Drivers pivoted to `Positive Drivers (+n)` / `Negative Drivers (+n)`
- 6 validity checks pivoted to `Check …` status columns
- 15 observation types pivoted to `… Mean` / `… n` daily aggregates
- Sessions aggregated per day: count, types, duration total, avg intensity,
  venues, opponents, surface, drill, air quality, temp, travel

### 3. `Sportmetryx_Athletes_Sessions_Joined.csv` — research dataset
`athletes.csv` ⋈ `sessions.csv` on `athlete_id`: **1,431 rows × 38 columns**.
Every session row with the athlete's features appended (prefixed `ath_`),
plus `date_iso`.

## Rebuild

```bash
cd data-combined
python3 build_combined_csv.py
```
